## 1. ระบบภาพ (Design tokens) — ทีม Design เป็นเจ้าของ

### 1.1 สี — ดึงจากหลังไพ่ backcard.png
| Token | ค่า | ใช้กับ |
|---|---|---|
| `--bg` | `#1B1226` | พื้นทุกหน้า (สีพื้นของหลังไพ่) |
| `--surface` | `#251A33` | การ์ด, แผง |
| `--sunk` | `#2F2240` | ช่องกรอก, แถบรอง |
| `--ink` | `#F4ECFA` | ตัวอักษรหลัก |
| `--muted` | `#B7A6C9` | ตัวอักษรรอง (contrast กับ bg ≈ 8:1) |
| `--gold` | `#E2C48A` | เส้นขอบ, ไอคอน, หัวเรื่อง (สีเส้นของหลังไพ่) |
| `--gold-strong` | `#D4AF5A` | ปุ่มหลัก, ป้าย |
| `--gold-soft` | `rgba(226,196,138,.14)` | พื้นชิปที่เลือก, glow อ่อน |
| `--mauve` | `#6E4C7A` | จุดกลุ่มดาว, เส้นแบ่งอ่อน (สีจุดของหลังไพ่) |
| `--line` | `rgba(226,196,138,.28)` | เส้นขอบการ์ด 1px |
| `--line-green` | `#06C755` | ปุ่ม LINE เท่านั้น (สีเดียวนอกพาเลต) |
| success / warning / danger | คงค่าเดิมใน `globals.css` | สถานะ |

- **พื้นหลัง**: `--bg` + radial glow มัวฟ์จางบนสุด (`rgba(110,76,122,.25)` รัศมี 600px) + เส้นกลุ่มดาว SVG โปร่ง 8% แบบ THAKSA (`screens/thaksa/02-landing-mobile.jpg`) — ทำเป็น component เดียวใช้ทุกหน้า
- **ทองเป็น "เส้นและแสง" ไม่ใช่พื้นเต็ม**: ปุ่มหลักเท่านั้นที่เป็นทองทึบ (THAKSA `06c-result-locked-deeper-mobile.jpg` ปุ่มทองไล่เฉด) ที่เหลือใช้ทองเป็นขอบ 1px, ไอคอน, และ glow
- **ห้ามใช้ม่วงสด `#7c3aed` เป็นพื้นปุ่ม/hero อีก** — ม่วงในระบบใหม่คือพื้น ไม่ใช่สี CTA

### 1.2 ตัวอักษร
| บทบาท | ฟอนต์ | เหตุผล |
|---|---|---|
| หัวเรื่องไทย (display) | **Trirong** 600 (Google Fonts) | serif ไทยมีหัว ดูหรูแบบ THAKSA/aitarot แต่ไม่ซ้ำใคร |
| หัวเรื่องอังกฤษ / โลโก้ | **Playfair Display** (มีอยู่แล้วใน `layout.tsx`) | ตรงกับ wordmark REFFORTUNE ที่เป็น serif ทอง |
| UI / เนื้อหา / ปุ่ม | **LINE Seed Sans TH** (มีอยู่แล้วใน `public/fonts/` 5 น้ำหนัก) | อ่านง่ายบนมือถือ เป็นฟอนต์ไทยแท้ ใช้แทน Inter ทั้งหมด |
| ตัวเลข/ตัวนับ | LINE Seed Sans TH Bold + `letter-spacing: .12em` + `tabular-nums` | แทน mono spaced caps ของ aitarot ("0 OF 3 SELECTED") |

สเกล (มือถือ): h1 30/1.25 · h2 22/1.3 · h3 18 · body 16/1.65 · caption 13 · label 12 uppercase `.08em` ทอง — เดสก์ท็อป h1 40

### 1.3 รูปทรง เงา แสง
- radius: การ์ด **12px**, bottom sheet 16px, ชิป/ปุ่มหลัก **999px** (แคปซูลแบบ THAKSA), ไพ่ 10px
- ขอบการ์ด: `1px solid var(--line)` + ขอบในจาง `inset 0 0 0 1px rgba(226,196,138,.08)` (Horachat `05-loading-deterministic-first-mobile.jpg` กรอบทองสองชั้น)
- glow ไพ่ที่เลือก: `0 0 24px rgba(226,196,138,.35)` + ยกขึ้น 12px
- เงาทั่วไป: `0 8px 28px rgba(0,0,0,.45)` — เลิก shadow สีม่วงทั้งหมด
- ไอคอน lucide stroke 1.5 สี `--gold`

### 1.4 การเคลื่อนไหว
- ไพ่กางเข้าจอ: stagger 30ms/ใบ, 400ms ease-out
- เลือกไพ่: ยกขึ้น + glow 180ms
- พลิกไพ่: 3D flip 600ms ทีละใบ (aitarot `04e-card-flip-mobile.jpg`)
- โหลด AI: จุด typing 3 จุดทอง (Horachat) — ห้าม spinner ทั่วไป
- `prefers-reduced-motion`: ไม่พลิก ไม่กาง ใช้ crossfade 200ms แทน

### 1.5 ของที่ Design ต้องผลิต
1. **Token file** (`globals.css` block ใหม่ + Figma variables) ตามตาราง 1.1–1.3
2. **หลังไพ่**: ใช้ `backcard.png` เดิม แต่ export ใหม่ 2 ขนาด (600×1050 สำหรับกางไพ่, 180×315 สำหรับกริด) — ตอนนี้ถูกย่อจนลายละเอียดหาย (`screens/reftirata/04c-card-pick-3of3-mobile.jpg`)
3. **กรอบหน้าไพ่**: overlay กรอบทอง 1px + แถบชื่อไพ่ภาษาไทยด้านล่าง ทับภาพ Rider–Waite 78 ใบที่มี (`public/card/00–21, c/p/s/w 1–14`) — ไม่ต้องวาดไพ่ใหม่ 78 ใบ
4. **พื้นหลังกลุ่มดาว** SVG 1 ไฟล์ (โปร่ง ใช้ทุกหน้า)
5. **การ์ดแชร์** เทมเพลต 1080×1350 + 1200×630: พื้น `--bg`, กรอบทอง, ไพ่ 1–3 ใบ, ชื่อไพ่ไทย, คำถาม, ชื่อลูกดวง, โลโก้, LINE OA — โดเมนต้องเป็นของจริง
6. **ภาพประกอบเซียมซี**: กระบอกแดง-ทองเดิมใช้ได้ (สีแดงเป็นสีของศาลเจ้า ถือเป็นข้อยกเว้นรายหน้า) แต่พื้นหลังต้องเป็น `--bg` ไม่ใช่ดำ
7. ไอคอนศาสตร์ 10 แบบ เส้นทอง (ทาโรต์ / ไพ่ประจำวัน / เซียมซี / เลขมงคล / ความรัก / โหราศาสตร์ / ราศีจีน / ชื่อ / วอลเปเปอร์ / spirit)
8. สถานะว่าง + โหลด (skeleton สีทองจาง shimmer)

## 2. สเปกรายหน้า — เอา look จากใคร ทำอะไร

รูปแบบเดสก์ท็อปทุกหน้า: `max-width: 1120px` เนื้อหา 2 คอลัมน์ (หลัก 720 + วิดเจ็ตข้าง 360 แบบ THAKSA `01-landing-desktop.jpg`) หน้าไพ่และเซียมซีอยู่กลางจอ `max-width: 640px` — เลิกยืดเลย์เอาต์มือถือเต็ม 1440px (`screens/reftirata/01-landing-desktop.jpg`)

### 2.1 หน้าแรก `src/app/page.tsx` — ต้นแบบ THAKSA
- **ตอนนี้** (`screens/reftirata/02-landing-mobile.jpg`): พื้นขาว hero ม่วงสด "ค้นหาคำตอบที่คุณตามหา" + ปุ่มขาว "เริ่มดูดวง" + การ์ดพาสเทล 4 สี + แพ็กเกจ 7 รายการ + ไอคอนเฟือง admin มุมขวาบน
- **ใหม่**:
  1. โลโก้ดาวเคราะห์ทองอยู่บนพื้นม่วงเข้ม (โลโก้ถูกออกแบบมาเพื่อพื้นนี้อยู่แล้ว) ขนาดเล็กลงเป็น app bar ไม่ใช่ hero
  2. **hero = คำถาม** (THAKSA `02-landing-mobile.jpg`): หัวเรื่อง Trirong "เรื่องไหนกำลังค้างอยู่ในใจคุณ?" + ช่องพิมพ์แคปซูลพื้น `--sunk` ปุ่มลูกศรทองกลม + ชิปหัวข้อแคปซูล (ความรัก / งาน / เงิน / สอบ / ไพ่วันนี้ / เซียมซี) ชิปที่เลือกขอบทอง
  3. **การ์ดผลทันทีจากวันเกิดช่องเดียว** (MuCraft `06-result-free-teaser-mobile.jpg`): ใส่วันเกิด → ธาตุ/ราศีจีน จาก `src/lib/chinese-zodiac/baseline.ts` + ป้าย "ตัวอย่างจากวันเกิดเท่านั้น"
  4. **แถววิดเจ็ตรายวัน**: ไพ่ประจำวัน (แสดง 7 วันเป็นจุด), เซียมซีวันนี้, วอลเปเปอร์ — การ์ด `--surface` ขอบทอง ไอคอนทอง ไม่ใช่การ์ด 4 สีพาสเทล
  5. **social proof** (AstroNeko `09-standout-mu-hub-live-counter-mobile.jpg`): "ดูดวงไปแล้ว X ครั้ง" + รีวิวภาพแชท LINE 3 ใบเลื่อนข้าง
  6. แพ็กเกจหมอดูคน: การ์ดแบบ THAKSA (รูปหมอดู, เรตติ้ง, "ตอบเฉลี่ย ~5 นาที", ปุ่มทอง ราคาบาท) — **ลบโปรที่หมดอายุ** และให้ราคาตรงกับ `/pricing`
  7. **ลบไอคอนเฟือง** `/admin-config-panel` ออกจากหน้าสาธารณะ
  8. bottom nav 5 แท็บคงไว้ แต่พื้น `--surface` ขอบบนทองจาง แท็บ active ไอคอนทอง + จุดทอง (THAKSA)

### 2.2 หน้าเริ่มทาโรต์ `src/app/tarot/page.tsx` — ต้นแบบ THAKSA + aitarot.pro
- **ตอนนี้** (`screens/reftirata/03-tarot-topic-mobile.jpg`): เลือกแค่จำนวนใบ 1/2/3/4/5/10 ไม่มีหัวข้อ ไม่มีคำถาม
- **ใหม่**: ลำดับ = ชิปหัวข้อ (ทั่วไป/ความรัก/การงาน/การเงิน) → ช่องคำถาม "ไม่บังคับ" + **ชิปตัวอย่างคำถามไทย** ("ช่วงนี้ควรโฟกัสเรื่องอะไร", "เขาคิดยังไงกับเรา", "ควรเปลี่ยนงานไหม") → เลือกรูปแบบไพ่ **ตั้งชื่อตามคำถาม** ไม่ใช่จำนวนใบ (aitarot `01-landing-desktop.jpg`: "ความรู้สึกของเขา", "ทางเลือก 2 ทาง", "อดีต-ปัจจุบัน-อนาคต", "เซลติกครอส 10 ใบ") โดยแสดงจำนวนใบเป็นตัวเล็ก
- **ห้าม** ใส่ข้อความแบบ THAKSA ว่า "คำอธิษฐานของคุณจะถูกเก็บไว้…" — ใช้ "คำถามนี้จะแนบไปกับไพ่ที่ส่งให้หมอดูเท่านั้น"

### 2.3 หน้าเลือกไพ่ `src/app/tarot/pick/PickClient.tsx` — ต้นแบบ aitarot.pro (ritual) + THAKSA (glow)
- **ตอนนี้** (`screens/reftirata/04c-card-pick-3of3-mobile.jpg`): กริด 13 คอลัมน์ × 6 แถว 78 ใบ ซ้อนกันจนลายหลังไพ่กลายเป็นแถบ, ใบที่เลือกกลายเป็นแถบม่วงมีเลข, ปุ่ม "สับไพ่ใหม่" และ "ดูผลทำนาย" ล้นขอบจอ, ไม่มีพลิกไพ่
- **ใหม่ (3 จังหวะ)**:
  1. **กาง**: เต็มจอพื้น `--bg` มีไพ่จางลอยเป็นฉากหลัง (aitarot `04c-card-ritual-3picked-mobile.jpg`) · หัวบรรทัด label ทอง "ตั้งจิตอธิษฐาน" + ตัวนับใหญ่ "เลือกแล้ว 0 / 3" + คำอธิบาย "แตะเพื่อเลือก · แตะซ้ำเพื่อยกเลิก" · ไพ่ **30 ใบ** สุ่มจาก 78 (engine ยัง deterministic ต่อ session) กริด 5 คอลัมน์ × 6 แถว ใบกว้าง ≥ 64px เห็นลาย backcard ชัด (aitarot `04-card-ritual-spread-mobile.jpg` แต่ใช้หลังไพ่ของเราซึ่งสวยกว่า) · ทางเลือกสำหรับไพ่ 1 ใบ: กางพัด 8 ใบแบบ THAKSA `04-card-spread-mobile.jpg`
  2. **เลือก**: ใบที่แตะยกขึ้น + glow ทอง + เลขลำดับในวงกลมทอง (ไม่ใช่แถบม่วงทึบ) แตะซ้ำยกเลิก · แถบล่างติดจอ: ปุ่ม ghost "สับใหม่" (ไอคอนอย่างเดียวบนจอแคบ) + ปุ่มทอง "เปิดไพ่" ทั้งคู่ **อยู่ในจอ** ที่ 390px (`flex` + `min-width:0`)
  3. **เปิด**: ไพ่ที่เลือกเรียงคว่ำ 3 ใบกลางจอ ป้ายไทยใต้ไพ่ "อดีต · ปัจจุบัน · อนาคต" (หรือชื่อตำแหน่งตาม spread) เส้นทองสั้นเหนือป้าย (aitarot `04d-reveal-prompt-mobile.jpg`) แตะทีละใบเพื่อพลิก 3D → เห็นหน้าไพ่ในกรอบทอง + ชื่อไทย/อังกฤษ → พลิกครบแล้วปุ่มทอง "ดูผล / ส่งให้หมอดู"
- a11y: ไพ่เป็น `<button aria-pressed>` มี focus ring ทอง 2px, ลูกศรเลื่อนได้, ตัวนับเป็น `aria-live="polite"`; reduced-motion → ไม่พลิก แสดงหน้าไพ่ทันที
