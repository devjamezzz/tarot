## ศาสตร์เซียมซีไทย (Esiimsi - Thai Bamboo Sticks)

**บทนำ:**
เซียมซี (Esiimsi) เป็นศาสตร์การเสี่ยงทายที่ได้รับอิทธิพลจากจีนและแพร่หลายในวัดไทย มีลักษณะเป็นติ้วไม้ไผ่บรรจุในกระบอกไม้ โดยมีหมายเลขกำกับไว้ที่ปลายแต่ละอัน ผู้เสี่ยงทายต้องเขย่ากระบอกจนกว่าจะมีติ้วหลุดออกมาเพียงอันเดียว

**ขั้นตอนและพิธีกรรม:**
1. **การตั้งจิตอธิษฐาน:** ผู้เสี่ยงทายต้องมีจิตใจสงบ ระบุคำถามที่ชัดเจน (มักเป็นเรื่องเฉพาะเจาะจง เช่น การงาน การเรียน ความรัก)
2. **การเขย่า (The Shake):** ถือกระบอกด้วยสองมือ เอียงเล็กน้อยแล้วเขย่าเป็นจังหวะจนกว่าจะมีติ้วหลุดออกมา
3. **การอ่านใบเซียมซี:** นำหมายเลขที่ได้ไปเทียบกับใบคำทำนาย ซึ่งมักแต่งเป็นบทร้อยกรอง (กลอน)

**จรรยาบรรณและการตีความ:**
- **ความแม่นยำขึ้นอยู่กับสมาธิ:** เชื่อว่าถ้าจิตใจไม่นิ่งหรือเขย่าออกมาหลายอันพร้อมกัน ผลอาจไม่แม่นยำ
- **การใช้ภาษา:** คำทำนายในเซียมซีมักมีทั้ง "ดี" "ปานกลาง" และ "ไม่ดี" แต่จะเน้นการให้ข้อคิดและแนวทางแก้ไขเสมอ
- **ข้อห้าม:** ห้ามเสี่ยงทายเรื่องเดิมซ้ำๆ ในวันเดียวกัน (ถือเป็นการไม่เคารพสิ่งศักดิ์สิทธิ์หรือพลังงาน)

**การนำมาใช้กับ AI (REFFORTUNE):**
- AI ต้องใช้ความรู้จากฐานข้อมูลเซียมซีมาตรฐานของไทย (เช่น ตำราวัดพระเชตุพนฯ หรือวัดเล่งเน่ยยี่) มาเป็นแนวทาง
- หากหมายเลขที่ระบุไม่มีใน Dataset ตัวอย่าง ให้ AI ใช้ "พลังงานของหมายเลข" ตามหลักเลขศาสตร์ไทยประกอบกับการทำนายเชิงบวกและสร้างสรรค์
- AI จะต้องสวมบทบาทเป็นผู้ถอดรหัสกลอนเซียมซีโบราณให้เป็นคำแนะนำร่วมสมัย

## ชุดข้อมูลหมายเลขเซียมซีมาตรฐาน (Core Dataset)

| หมายเลข | พลังงานหลัก | คำทำนายเชิงลึก |
| :--- | :--- | :--- |
| 1 | การเริ่มต้นใหม่ | **ความหมาย:** เหมือนอรุณรุ่งที่ขอบฟ้า อุปสรรคที่เคยมีจะมลายหายไป **การงาน:** เริ่มโปรเจกต์ใหม่ได้ดี **ความรัก:** จะมีคนดีเข้ามาแนะนำ |
| 2 | ความเมตตา | **ความหมาย:** มีผู้ใหญ่คอยเกื้อหนุนเหมือนปลาได้น้ำ **การงาน:** เจรจาราบรื่น **ความรัก:** เข้าใจกันมากขึ้น |
| 3 | การต่อสู้ | **ความหมาย:** ต้องออกแรงเหนื่อยก่อนจึงจะเห็นชัยชนะ **การงาน:** มีคู่แข่งแต่ชนะได้ **ความรัก:** ต้องใช้ความพยายามพิสูจน์ใจ |
| 4 | สติปัญญา | **ความหมาย:** ใช้ความรู้ความสามารถนำพาความสำเร็จ **การงาน:** งานวิชาการ/วางแผนเด่น **ความรัก:** ใช้เหตุผลนำอารมณ์ |
| 5 | ความมั่นคง | **ความหมาย:** สิ่งที่ทำอยู่จะรากฐานแข็งแกร่ง **การงาน:** ได้เลื่อนตำแหน่งหรือขยับขยาย **ความรัก:** พัฒนาไปสู่ความมั่นคง |
| 6 | โชคลาภ | **ความหมาย:** จะมีลาภลอยหรือข่าวดีจากแดนไกล **การงาน:** ได้งานที่ไม่คาดฝัน **ความรัก:** พบรักระหว่างเดินทาง |
| 7 | ความอดทน | **ความหมาย:** งานหนักและภาระเยอะ ต้องหนักแน่นดั่งขุนเขา **การงาน:** ระวังความเครียดสะสม **ความรัก:** ช่วงเวลาพิสูจน์ความซื่อสัตย์ |
| 8 | การเปลี่ยนแปลง | **ความหมาย:** ถึงเวลาละทิ้งสิ่งเก่าเพื่อรับสิ่งใหม่ที่ดีกว่า **การงาน:** ย้ายงานหรือเปลี่ยนวิธีทำจะรุ่ง **ความรัก:** มีการเริ่มต้นใหม่ |
| 9 | ความสำเร็จสูงสุด | **ความหมาย:** สิ่งศักดิ์สิทธิ์คุ้มครอง ทำอะไรก็ขึ้น **การงาน:** ปังระดับสูงสุด **ความรัก:** สมหวังดังปรารถนา |
| 10 | การสิ้นสุดและเริ่มใหม่ | **ความหมาย:** จบวงจรเดิมเพื่อเริ่มต้นสิ่งใหม่ที่ยิ่งใหญ่กว่า **การงาน:** ปิดดีลใหญ่สำเร็จ **ความรัก:** ปรับความเข้าใจครั้งใหญ่ |
| 11 | รอคอยฤดูกาล | **ความหมาย:** สิ่งที่หวังยังไม่ถึงเวลา เหมือนเมล็ดที่เพิ่งหว่านลงดิน ต้องดูแลต่อไปโดยไม่เร่งผล **การงาน:** งานที่ยื่นขอหรือรอคำตอบจะช้ากว่าที่คิด แต่ยังมีความหวัง **ความรัก:** อย่าเร่งอีกฝ่ายให้ตอบ ให้เวลาความรู้สึกได้เติบโตเอง **คำแนะนำ:** ทำหน้าที่ของคุณให้ดีในแต่ละวัน แล้วปล่อยเรื่องเวลาให้เป็นไปตามจังหวะของมัน **โชค:** กลาง |
| 12 | น้ำขึ้นให้รีบตัก | **ความหมาย:** โอกาสมาถึงตรงหน้าแล้ว จังหวะแบบนี้ไม่ได้มีบ่อย ใครลงมือก่อนจะได้ผลก่อน **การงาน:** ข้อเสนอหรือโอกาสงานที่เข้ามาช่วงนี้ควรตอบรับเร็ว **ความรัก:** ถ้ามีคนในใจ ให้แสดงออกก่อนที่จังหวะจะผ่านไป **คำแนะนำ:** ตัดสินใจให้ไว แต่ยังต้องอ่านเงื่อนไขให้ครบก่อนลงชื่อ **โชค:** ดี |
| 13 | เมฆบังจันทร์ | **ความหมาย:** มีอุปสรรคหรือความไม่ชัดเจนมาบดบังชั่วคราว ไม่ใช่เรื่องถาวร แต่ต้องรอให้ผ่านไปก่อน **การงาน:** อาจถูกเข้าใจผิดหรือมีเรื่องติดขัด อย่าเพิ่งเริ่มโครงการใหญ่ในช่วงนี้ **ความรัก:** มีเรื่องเข้าใจผิดหรือคนที่สามมาทำให้ขุ่นมัว พูดคุยกันตรง ๆ จะดีที่สุด **คำแนะนำ:** ชะลอการตัดสินใจสำคัญไว้ก่อน รอให้ข้อมูลครบและใจสงบกว่านี้ **โชค:** ควรระวัง |
| 14 | ข้าวรวงทองรอเก็บเกี่ยว | **ความหมาย:** ความพยายามที่ผ่านมากำลังออกผล ช่วงนี้เป็นเวลาเก็บเกี่ยวสิ่งที่คุณลงแรงไว้ **การงาน:** ผลงานที่ทำมานานได้รับผลตอบแทน อาจได้โบนัส ค่าตอบแทน หรือคำชม **ความรัก:** ความจริงใจที่ให้ไปจะได้รับกลับมา ความสัมพันธ์มีความสุขและมั่นคง **คำแนะนำ:** เก็บออมส่วนหนึ่งจากผลที่ได้ และขอบคุณคนที่ช่วยคุณมาตลอดทาง **โชค:** ดี |
| 15 | เรือทวนน้ำ | **ความหมาย:** เหมือนพายเรือทวนน้ำ ทุกอย่างต้องใช้แรงมากกว่าปกติ หยุดเมื่อไรจะถอยหลังทันที **การงาน:** งานติดขัดหลายด้าน ต้องอาศัยทีมและความต่อเนื่อง อย่าทำคนเดียว **ความรัก:** ความสัมพันธ์ต้องประคองด้วยความเข้าใจจากทั้งสองฝ่าย **คำแนะนำ:** ตั้งเป้าเล็ก ๆ ทีละขั้น และขอความช่วยเหลือเมื่อจำเป็น ไม่ใช่เรื่องน่าอาย **โชค:** ควรระวัง |
| 16 | ดอกบัวพ้นน้ำ | **ความหมาย:** ผ่านช่วงยากมาได้อย่างสง่างาม ความดีและความตั้งใจของคุณจะเป็นที่ประจักษ์ **การงาน:** ชื่อเสียงและความน่าเชื่อถือเพิ่มขึ้น เหมาะกับการเสนอตัวหรือรับบทบาทใหม่ **ความรัก:** ความรักที่บริสุทธิ์ใจจะได้รับการตอบรับ ความสัมพันธ์สะอาดชัดเจน **คำแนะนำ:** รักษาความตรงไปตรงมาไว้ นั่นคือสิ่งที่ทำให้คุณโดดเด่นกว่าคนอื่น **โชค:** ดี |
| 17 | เสือซ่อนเล็บ | **ความหมาย:** คุณมีความสามารถพร้อมอยู่แล้ว แต่ยังไม่ถึงจังหวะที่จะแสดงออก การรอที่ถูกต้องคือพลัง **การงาน:** เก็บฝีมือไว้ก่อน สังเกตสถานการณ์ให้รอบด้าน แล้วลงมือเมื่อโอกาสเปิด **ความรัก:** อย่ารีบเปิดใจทั้งหมด ดูให้ชัดว่าอีกฝ่ายจริงจังแค่ไหน **คำแนะนำ:** เตรียมตัวเงียบ ๆ ให้พร้อมที่สุด เมื่อโอกาสมาคุณจะไม่พลาด **โชค:** กลาง |
| 18 | ฝนตกทั่วฟ้า | **ความหมาย:** ความอุดมสมบูรณ์และน้ำใจจากคนรอบข้าง เรื่องที่เคยแห้งแล้งจะกลับมามีชีวิตอีกครั้ง **การงาน:** ได้รับความช่วยเหลือจากเพื่อนร่วมงานและคู่ค้า งานที่ชะงักกลับมาเดินหน้า **ความรัก:** ครอบครัวและคนรักให้ความอบอุ่น เรื่องที่เคยห่างเหินจะกลับมาใกล้ชิด **คำแนะนำ:** รับน้ำใจด้วยความขอบคุณ แล้วส่งต่อให้คนอื่นบ้างเมื่อคุณมีโอกาส **โชค:** ดี |
| 19 | ทางแยกสองแพร่ง | **ความหมาย:** คุณกำลังอยู่ตรงทางเลือกสำคัญ ไม่มีทางไหนผิด แต่ต้องเลือกด้วยใจของตัวเองแล้วเดินให้สุด **การงาน:** มีสองทางให้เลือก เช่น อยู่ต่อหรือย้าย ทำเดิมหรือลองใหม่ ตัดสินใจจากเป้าหมายระยะยาว **ความรัก:** ต้องเลือกระหว่างความสบายใจกับความท้าทาย ซื่อสัตย์กับความรู้สึกตัวเอง **คำแนะนำ:** เขียนข้อดีข้อเสียของแต่ละทางลงกระดาษ แล้วเลือกทางที่คุณจะไม่เสียใจในอีก 5 ปี **โชค:** กลาง |
| 20 | หงส์คู่ในสระ | **ความหมาย:** ใบแห่งความรักและคู่ครอง ความสัมพันธ์จะเคียงข้างกันอย่างมั่นคง คนโสดมีเกณฑ์พบคนที่ใช่ **การงาน:** การร่วมงานเป็นคู่หรือเป็นทีมให้ผลดี พันธมิตรใหม่เข้ามาช่วยเสริม **ความรัก:** สมหวังในความรัก คู่ที่คบกันอยู่มีเกณฑ์ตกลงปลงใจกันมากขึ้น **คำแนะนำ:** ให้เวลากับคนสำคัญมากขึ้น และบอกความรู้สึกดี ๆ ออกไปโดยไม่ต้องรอโอกาสพิเศษ **โชค:** ดี |
| 21 | ไฟไหม้ฟาง | **ความหมาย:** สิ่งที่ดูร้อนแรงตอนนี้อาจอยู่ไม่นาน ระวังความตื่นเต้นชั่วคราวที่ทำให้ตัดสินใจพลาด **การงาน:** ข้อเสนอที่ดูดีเกินจริงควรตรวจสอบให้ละเอียด อย่าลงทุนทั้งหมดในสิ่งเดียว **ความรัก:** ความสัมพันธ์ที่มาเร็วอาจไปเร็ว ให้เวลาทำความรู้จักกันก่อนผูกมัด **คำแนะนำ:** อย่าใช้เงินก้อนใหญ่หรือให้คำสัญญาสำคัญในช่วงที่อารมณ์กำลังพุ่ง **โชค:** ควรระวัง |
| 22 | เดินทางไกล | **ความหมาย:** มีเกณฑ์เดินทาง ย้ายที่ หรือเปลี่ยนสภาพแวดล้อม ระหว่างทางมีทั้งความเหนื่อยและสิ่งใหม่ที่คุ้มค่า **การงาน:** งานที่เกี่ยวกับการเดินทาง ต่างจังหวัด หรือต่างประเทศให้ผลดี การย้ายสายงานเป็นไปได้ **ความรัก:** ความรักระยะไกลต้องอาศัยความไว้ใจ หรืออาจพบคนใหม่ในที่ที่ไม่คุ้นเคย **คำแนะนำ:** วางแผนเรื่องค่าใช้จ่ายและสุขภาพให้ดีก่อนออกเดินทางหรือเปลี่ยนแปลงครั้งใหญ่ **โชค:** กลาง |
| 23 | มังกรขึ้นฟ้า | **ความหมาย:** ความก้าวหน้าเหนือความคาดหมาย ฐานะ ตำแหน่ง หรือชื่อเสียงจะขยับขึ้นอย่างรวดเร็ว **การงาน:** มีเกณฑ์เลื่อนขั้น ได้รับมอบหมายงานใหญ่ หรือธุรกิจเติบโตแบบก้าวกระโดด **ความรัก:** คนรักภูมิใจในตัวคุณ คนโสดจะเป็นที่หมายปองของคนรอบข้าง **คำแนะนำ:** ยิ่งขึ้นสูงยิ่งต้องถ่อมตน อย่าลืมคนที่เคยช่วยเหลือคุณในวันที่ยังไม่มีอะไร **โชค:** ดี |
| 24 | ลมพัดกิ่งไผ่ | **ความหมาย:** มีแรงกดดันจากภายนอกเข้ามา แต่ถ้ารู้จักยืดหยุ่นและปรับตัว คุณจะผ่านไปได้โดยไม่เสียหาย **การงาน:** นโยบายหรือหัวหน้าเปลี่ยน ต้องปรับวิธีทำงาน อย่าฝืนหรือต่อต้านโดยไม่จำเป็น **ความรัก:** มีเรื่องกระทบกระทั่งจากคนรอบข้าง ประคองกันด้วยความเข้าใจ อย่าดึงดันเอาชนะ **คำแนะนำ:** ยอมโอนอ่อนในเรื่องเล็ก เพื่อรักษาสิ่งใหญ่ที่สำคัญกว่าไว้ **โชค:** กลาง |
| 25 | น้ำนิ่งไหลลึก | **ความหมาย:** ความสงบคือพลังของคุณในช่วงนี้ สิ่งที่ทำอย่างเงียบ ๆ และต่อเนื่องจะให้ผลลึกซึ้งกว่าความหวือหวา **การงาน:** งานที่ต้องใช้สมาธิ ความละเอียด และความน่าเชื่อถือจะโดดเด่น ไม่ต้องรีบโชว์ผลงาน **ความรัก:** ความรักที่เรียบง่ายและมั่นคง คนที่พูดน้อยแต่ทำจริงคือคนที่ใช่ **คำแนะนำ:** หาเวลาอยู่กับตัวเองเงียบ ๆ วันละนิด คำตอบที่คุณหาอยู่จะชัดขึ้นเอง **โชค:** ดี |
| 26 | เงาในกระจก | **ความหมาย:** ระวังสิ่งที่ดูเหมือนจริงแต่ไม่จริง ทั้งคำพูด ข้อเสนอ และคนที่เข้ามาใกล้ในช่วงนี้ **การงาน:** ตรวจสอบสัญญา ตัวเลข และคำสัญญาให้ครบ อย่าเชื่อคำพูดโดยไม่มีหลักฐาน **ความรัก:** ระวังคำหวานที่ไม่มีการกระทำรองรับ ดูจากสิ่งที่เขาทำ ไม่ใช่สิ่งที่เขาพูด **คำแนะนำ:** ถ้าไม่แน่ใจให้ถามตรง ๆ และขอเวลาคิด อย่าให้ใครเร่งคุณตัดสินใจ **โชค:** ควรระวัง |
| 27 | ดวงดาวนำทาง | **ความหมาย:** จะมีผู้ชี้ทางหรือผู้ช่วยเหลือปรากฏในช่วงที่คุณสับสน ฟังคำแนะนำนั้นให้ดี **การงาน:** ได้ที่ปรึกษาหรือผู้ใหญ่ที่เข้าใจคุณ งานที่หลงทางอยู่จะกลับมาถูกทิศ **ความรัก:** เพื่อนหรือคนใกล้ตัวจะแนะนำคนดีให้ หรือช่วยให้คุณเห็นความสัมพันธ์ชัดขึ้น **คำแนะนำ:** เปิดใจรับคำแนะนำจากคนที่หวังดี แต่ตัดสินใจสุดท้ายด้วยตัวเอง **โชค:** ดี |
| 28 | พระจันทร์เต็มดวง | **ความหมาย:** ความสมบูรณ์พร้อม สิ่งที่รอคอยมานานกำลังจะครบถ้วนอย่างที่ตั้งใจ **การงาน:** โครงการที่ทำมายาวนานจะสำเร็จครบถ้วน เป็นช่วงเก็บเกี่ยวชื่อเสียงและผลตอบแทน **ความรัก:** ความสัมพันธ์เต็มเปี่ยม คู่ที่รอคำตอบจะได้คำตอบที่ดี **คำแนะนำ:** ชื่นชมสิ่งที่มีอยู่ตรงหน้าให้เต็มที่ และเตรียมวางแผนรอบใหม่เมื่อรอบนี้ครบสมบูรณ์ **โชค:** ดี |

## บทกลอนประจำใบเซียมซี (1–28)

บทกลอน 4 บรรทัดที่แสดงบนหน้าเว็บคู่กับคำทำนายพื้นฐานของแต่ละใบ:

- ใบที่ 1 — การเริ่มต้นใหม่ (โชค: ดี): อรุณรุ่งทอแสงที่ขอบฟ้า / เมฆหมอกลาลับไปไม่หวนคืน / ทางข้างหน้าโล่งกว้างให้ก้าวยืน / เริ่มสิ่งใหม่ในวันนี้ดีนักแล
- ใบที่ 2 — ความเมตตา (โชค: ดี): ปลาได้น้ำสำราญในสายธาร / ผู้ใหญ่ท่านเมตตาพาส่งเสริม / เจรจาสิ่งใดได้ดั่งเติม / ความดีเดิมส่งผลให้ผลิบาน
- ใบที่ 3 — การต่อสู้ (โชค: กลาง): หนทางนี้มีหนามขวางแนวทาง / ต้องออกแรงอย่างหนักจึงจักผ่าน / ชัยชนะรออยู่ปลายเส้นทาง / ผู้อดทนย่อมได้ครองชัยชาญ
- ใบที่ 4 — สติปัญญา (โชค: ดี): ตะเกียงน้อยส่องทางกลางราตรี / ผู้มีปัญญาเห็นทางแม้ทางมืด / คิดให้รอบก่อนลงมือถือดี / ความสำเร็จตามมาด้วยวิชา
- ใบที่ 5 — ความมั่นคง (โชค: ดี): ต้นไม้ใหญ่รากหยั่งลึกถึงดิน / ลมพายุพัดมาไม่สั่นคลอน / สิ่งที่ทำวันนี้จักถาวร / ค่อยก่อร่างสร้างฐานให้มั่นคง
- ใบที่ 6 — โชคลาภ (โชค: ดี): นกน้อยบินข้ามฟ้ามาแต่ไกล / คาบข่าวดีมาให้ถึงเรือนชาน / ลาภลอยมาไม่คาดฝันบันดาล / เปิดประตูรับโชคที่มาเยือน
- ใบที่ 7 — ความอดทน (โชค: ควรระวัง): ขุนเขาใหญ่ยืนนิ่งกลางพายุ / ฝนกระหน่ำก็ไม่หลุดจากที่ตั้ง / ภาระหนักวันนี้จงหนักแน่น / อดทนไว้ไม่แคลนฟ้าจะเปิด
- ใบที่ 8 — การเปลี่ยนแปลง (โชค: กลาง): ใบไม้เก่าร่วงลงจากกิ่งก้าน / เพื่อใบใหม่แตกยอดในฤดูหน้า / ปล่อยวางสิ่งเดิมที่ผ่านมา / สิ่งใหม่ดีกว่ารออยู่ข้างหน้า
- ใบที่ 9 — ความสำเร็จสูงสุด (โชค: ดี): ดวงตะวันขึ้นสูงกลางนภา / แสงส่องทั่วหล้าไม่มีที่บัง / สิ่งศักดิ์สิทธิ์คุ้มครองอยู่เบื้องหลัง / ทำสิ่งใดสมหวังดั่งใจปอง
- ใบที่ 10 — การสิ้นสุดและเริ่มใหม่ (โชค: กลาง): ฤดูหนึ่งจบลงตามกาลเวลา / ฤดูใหม่ก็มาตามครรลอง / ปิดบทเก่าที่เคยได้จับจอง / เปิดหน้าใหม่ให้ยิ่งใหญ่กว่าเดิม
- ใบที่ 11 — รอคอยฤดูกาล (โชค: กลาง): เมล็ดพันธุ์ยังฝังอยู่ใต้ดิน / ยังไม่ถึงเวลาที่จะงอกงาม / รดน้ำไปอย่าเร่งอย่าถามความ / เมื่อถึงยามดอกผลจะผลิบาน
- ใบที่ 12 — น้ำขึ้นให้รีบตัก (โชค: ดี): น้ำขึ้นเต็มฝั่งในยามนี้ / โอกาสดีมาถึงอย่ารอช้า / รีบตักไว้ก่อนน้ำจะลดลา / ผู้กล้าคว้าย่อมได้ดั่งใจหวัง
- ใบที่ 13 — เมฆบังจันทร์ (โชค: ควรระวัง): เมฆดำลอยมาบดบังจันทร์ / แสงสว่างพลันหม่นไปชั่วคราว / รอสักนิดเมฆจะผ่านพ้นราว / จันทร์จะฉายแสงสกาวดังเดิมมา
- ใบที่ 14 — ข้าวรวงทองรอเก็บเกี่ยว (โชค: ดี): ทุ่งข้าวเหลืองอร่ามรอเก็บเกี่ยว / เหงื่อที่เคยหลั่งไหลไม่สูญเปล่า / ถึงเวลาเก็บผลที่หว่านเอา / ยุ้งฉางเราจะเต็มในปีนี้
- ใบที่ 15 — เรือทวนน้ำ (โชค: ควรระวัง): เรือน้อยพายทวนสายน้ำเชี่ยว / ออกแรงเดียวไม่พอต้องพร้อมใจ / วางพายเมื่อใดถอยหลังไป / ค่อยฝ่าไปทีละวาจะถึงฝั่ง
- ใบที่ 16 — ดอกบัวพ้นน้ำ (โชค: ดี): บัวพ้นน้ำชูช่อรับตะวัน / ผ่านโคลนตมมานั้นไม่แปดเปื้อน / ความดีที่ทำจะไม่ลบเลือน / ชื่อเสียงเรือนจะขจรไปไกล
- ใบที่ 17 — เสือซ่อนเล็บ (โชค: กลาง): เสือใหญ่หมอบนิ่งอยู่ในพง / ไม่ผลีผลามลงจนกว่าจังหวะ / ผู้รู้รอย่อมได้ชัยชนะ / เมื่อถึงคราวจะกระโจนไม่พลาดเป้า
- ใบที่ 18 — ฝนตกทั่วฟ้า (โชค: ดี): ฝนโปรยปรายชุ่มฉ่ำทั่วแผ่นดิน / ไร่นาสิ้นความแล้งกลับเขียวขจี / ผู้คนรอบตัวจะช่วยเหลือดี / ความอุดมสมบูรณ์มีมาเยือน
- ใบที่ 19 — ทางแยกสองแพร่ง (โชค: กลาง): ถึงทางแยกสองสายให้เลือกเดิน / ทางหนึ่งเพลินทางหนึ่งเงียบสงบ / ฟังใจตนก่อนตัดสินให้จบ / เลือกแล้วก้าวอย่าเหลียวมองหลัง
- ใบที่ 20 — หงส์คู่ในสระ (โชค: ดี): หงส์คู่ลอยล่องในสระใส / ต่างเคียงกันไปไม่ห่างหาย / ความรักสมหวังทั้งใจกาย / ผู้เดียวดายจะได้พบเนื้อคู่
- ใบที่ 21 — ไฟไหม้ฟาง (โชค: ควรระวัง): ไฟลุกโชนไหม้ฟางเพียงครู่เดียว / สว่างเปรี้ยวแล้วดับไปไม่เหลือ / สิ่งใดที่ดูดีอย่ารีบเชื่อ / เผื่อใจไว้อย่าทุ่มจนหมดตัว
- ใบที่ 22 — เดินทางไกล (โชค: กลาง): เก็บกระเป๋าออกเดินสู่ทางไกล / ทิ้งที่เก่าไปพบที่ใหม่กว่า / มีทั้งเหนื่อยทั้งสุขในระหว่างทาง / ถึงปลายทางจะพบสิ่งที่ตามหา
- ใบที่ 23 — มังกรขึ้นฟ้า (โชค: ดี): มังกรผงาดทะยานขึ้นสู่ฟ้า / เมฆหมอกพาส่งเสริมให้สูงลิ่ว / ความก้าวหน้ามาไวเกินคาดฝัน / จงยืนมั่นถ่อมตนอย่าลืมตัว
- ใบที่ 24 — ลมพัดกิ่งไผ่ (โชค: กลาง): ลมแรงพัดกิ่งไผ่โอนเอนไป / ไผ่ไม่หักเพราะรู้จักลู่ลม / ยืดหยุ่นไว้ในยามที่ระทม / เมื่อลมสงบไผ่ก็ตั้งตรงดังเดิม
- ใบที่ 25 — น้ำนิ่งไหลลึก (โชค: ดี): น้ำนิ่งลึกไม่มีเสียงคลื่นดัง / แต่มีพลังไหลอยู่ภายใน / ผู้สงบย่อมเห็นทางที่ควรไป / ใจนิ่งไว้แล้วปัญญาจะปรากฏ
- ใบที่ 26 — เงาในกระจก (โชค: ควรระวัง): เงาในกระจกดูเหมือนคนจริง / แต่ยื่นมือจับสิ่งนั้นก็หาย / คำหวานใดฟังแล้วอย่าวางใจ / ดูให้ชัดก่อนไว้ใจใครทั้งสิ้น
- ใบที่ 27 — ดวงดาวนำทาง (โชค: ดี): ดาวดวงหนึ่งส่องแสงในคืนมืด / นำทางผู้หลงยืดสู่จุดหมาย / จะมีผู้ช่วยเหลือมาใกล้กาย / เดินตามแสงไปไม่หลงทาง
- ใบที่ 28 — พระจันทร์เต็มดวง (โชค: ดี): จันทร์เต็มดวงกระจ่างกลางเวหา / ส่องแสงนวลทั่วหล้าไม่มีบัง / สิ่งที่รอมานานจะสมหวัง / ความสมบูรณ์พร้อมพรั่งในคืนนี้

*(หมายเหตุ: ตารางและบทกลอนครอบคลุมใบที่ 1–28 ตามมาตรฐานเซียมซีไทยทั่วไป และตรงกับตำราที่แสดงในระบบ)*
